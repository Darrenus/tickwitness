# ADR0050: One detached-member EC2 qualification retaining twenty-one admissions

Date: 2026-11-27 Asia/Singapore. Status: accepted for this bounded internal reference;
implementation begins only after actual freeze commit push and remote readback.

## Problem

The third actual AWS qualification retained18 PASS controls and one admitted
UNKNOWN at detached control19; five controls were never admitted. Its assessor
required guest namespace columns on a legitimate host-only bwrap monitor. The
corrected four-role classifier and meaningful producer/decision regressions
passed remote checks. Subsequent installed regressions corrected two independent
smoke assumptions while keeping the original deadlines, research budget and
product controls. Complete corrected-source CI remains source evidence, not a
new actual host qualification or permission to reopen consumed v2.

The owner explicitly requests continued actual AWS verification, remote-only
tests, automatic Stop and external-human reproduction still PENDING. Earlier
SSH loss also showed that a correct bounded on-disk archive can exist while
shutdown interrupts its live journal forwarding. A bounded direct-download
handoff is required before ending the original lifecycle guard.

## Decision

Freeze [one-use recovery v3](../contracts/restricted-reference-ec2-recovery-v3.md)
before implementation. Permit exactly fixed plan `ec2-recovery-20261127-v3`, run
`ec201aab11254e8bb7cd1573a96a0004`, on the same selected instance. Retain original,
recovery-v1 and recovery-v2 actual histories and all their byte/inode identities.
Their charges1+1+19 remain21; the new complete24-control catalog has its original
600s admission/30s setup and unchanged per-task10s+2s controls, for cumulative
ceiling45. Schema3 does not mean historical count3. Original research budgets
remain common and unchanged; no research slot or replay is added.

Use separate fixed v3 plan/consumption/Stop/stage/operation paths, schema3 kinds,
an explicit factory/CLI selection and exact typed record shapes. The original
read-only host claim still provides exclusive admission. A separate exclusive
operation fence precedes preparation; durable global consumption precedes run,
metadata or policy. Partial or uncertain records stay consumed and are never
reset. Preserve default/v1/v2, including v2 USED and its old ceiling26. No generic
recovery, automatic fifth qualification or reuse of old PASS controls is added.

Bind the three-entry history and all nineteen run0003 cases to their original
raw bytes, ticket/nonce/outcome/report/source/boot and accounting phases. Keep
run0003 TERMINAL/NOT_QUALIFIED, poisoned=false,18 PASS/one admitted UNKNOWN/five
unadmitted and null successful SHA/receipt. Its historical manifest remains0/2
and final report19/21. Do not reevaluate it with the corrected assessor. The new
1222-byte Stop observation describes the later read-only retrieval boot, not
another qualification or charge. Old authority can only be inspected inertly.

Keep the original lifecycle wrapper/four-hour guard and Stop hook. A thin shell
execs the root timeout and one stdlib Python Controller master, whose production
phase/export/internal-wait methods have narrow injectable ports for remote
regression. Public operations are run/ack/cancel; a public wait mode cannot
reconstruct an anchor. The controller has outer1500s+2s, preparation480s+2s,
qualifier612s+2s, one export25s+2s/16MiB and handoff at most120s. The qualifier's
extra12s is only existing2s stop confirmation and at most10s report/receipt
finalization; its600s admission clock never grows. Each phase is also capped by
the original outer deadline. Qualifier/export each run at most once.

An independent SSH stream verifies the complete existing archive locally before
the fixed acknowledgement helper publishes O_EXCL/fsynced ACK. Bind source,
run, boot, unit invocation/MainPID, controllerPID/start identities, exact commands,
nonce and original archive bytes/SHA; validate within the same original120s.
ControllerPID is the actual live Python master; it is distinct from a presumed
Bash parent or the unit's separately bound MainPID. Ready/ACK stay outside the
already published archive and are retained independently, avoiding self-reference.
Wrong/stale ACK writes nothing and grants no extension. Valid ACK returns the
original qualifier code only for a launched qualifier with an actually observed
normal0..255 code, and exits into automatic Stop. Uninvoked/unknown qualification,
negative child code, phase timeout or missing/failed transport returns74. Preserve
actual signed preparation/qualifier exit and qualification records; null never
becomes0 and negative codes are not misrepresented by modulo256 process exit.
The exact final controller-result record is separate from the previously
published archive. Receipt verification
occurs in the original live boot; later readback
never reconstructs an old live authority or poisons historical state.

The master creates one exclusive export-call fence; its single child proves the
parent's original identity and creates a separate exclusive export-consumption
before archive.pending. Neither partial record grants another export. Cancel
validates the live start/guard/master identities even before ready, exclusively
records the request, rechecks the guard and cancels the original unit. Unknown
acknowledgements and partial cancel/export fences are retained without automatic
retransmission. All operational shapes and bounds are fixed by the contract.

## Consequences

This fixed allowance is more explicit than a reusable retry mechanism and keeps
technical admissions separate from research execution. The operational packet's
three Git-bound scripts are separate from the fixed ten-file qualification
source closure. New implementation requires fresh complete remote source checks
and controller/handoff negative regressions before a reviewed actual package is
started. Root owner/OS trust and owner Stop/ACK provenance are explicit limits.

Qualification, export, handoff and Stop outcomes remain distinct. Disconnect,
bad download or late acknowledgement never rewrites a committed report or turns
an unknown outcome into a refund, rerun or success. Every path retains evidence
and ends with the unchanged automatic Stop plus independent AWS readback; any
later recovery is read-only and separately bounded. M1 stays DISABLED, PR115
Draft/#38 incomplete, human review NOT_PERFORMED and external-human reproduction
0/0/PENDING even if the new reference catalog fully passes.
