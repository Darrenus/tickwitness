# Sprint backlog

状态：Proposed（拟议 backlog，尚未实现）。版本：2026-10-25。项目：TickWitness；目标仓库：`Darrenus/tickwitness`。当前交付是 planning baseline，S4 才计划交付 0.1 技术预览。

配套阅读：[路线图与验收门](roadmap.md)。以下故事是未来工作，不表示功能已经存在。S1–S4 可进入近期排程；S5 以后是依赖明确的规划 backlog，每两次 Sprint 按实际发现滚动细化。

## 使用规则

- 一个 Sprint 为两周，50 小时净工程容量；可计划专项不超过 35 小时，另留 15 小时给日常回归、审阅、文档、依赖与维护。专项包括功能、访谈、专门验证和演练，其专门验收已经计入故事；公共日常工作只记账一次，不重复占用两项预算。
- 工作量 `S` 约 4–8 小时、`M` 约 9–12 小时、`L` 约 13–16 小时。估计不表示承诺；单个故事超过 16 小时必须拆分。
- 每个故事都应引用领域责任、输入/输出契约、验收测试和文档变更。新依赖、持久化模型变化或领域语义变化应有 ADR。
- 代码生成、实现自测和作者自审不算独立评审。单维护者无法获得独立审核时，明确标记；涉及高风险隔离或正确性发布门槛时邀请外部审阅，未完成前限制发布范围。
- `Definition of Ready`：用户价值、范围、契约、依赖、可执行验收、数据许可与运行信任模型清晰；没有 unresolved 的阻塞决策。
- `Definition of Done`：实际纵向路径工作；正负例与故障例通过；领域不变量有验证；文档与版本记录更新；产物可重现；无假成功、无虚构指标；符合对应阶段的发布与安全门槛。
- 研究性 spike 按每段不超过 6 小时的 timebox 执行，结束产出证据与决策；超过 16 小时的故事硬拆，不能通过标为 spike 绕过。
- 核心 GA 范围为 CLI/SDK、受约束搜索、证据与作业可靠性。HTTP/MCP/查看器是条件性可选入口：有真实需求且通过各自门槛才发行；否则同预算替换为核心加固故事，不叠加范围，也不阻塞核心 GA。

**目标：** 比较候选引擎可行性，开始近期痛点访谈，建立最小开发入口。依赖：无。计划专项容量 32 小时。

| Story | 用户故事与任务 | 估计 | 可执行验收 |
| --- | --- | --- | --- |
| S01-01 / E02、E03 | 作为维护者，我需要比较 HftBacktest/NautilusTrader 候选：两个各 5h 的 timebox，分别做平台/许可/能力比较与最小 trace 试验，暂不写正式适配器 | M / 10h | 有固定版本、必要轨迹与缺口清单；S2 可据此定默认引擎；无法取得关键轨迹时记录 no-go |
| S01-02 / E09 | 作为贡献者，我需要最小 Python 包骨架、锁定依赖、lint/type/test 入口和 CI；代码使用 Apache-2.0，第三方许可分别核对 | S / 8h | 干净目录可运行最小检查；CI 使用相同入口，失败检查能使 CI 失败；不构建无用模块脚手架 |
| S01-03 / E02、E10 | 作为维护者，我需要招募、完成并整理首批 2–3 次近期痛点访谈，形成一个可反驳声明草案和术语卡；招募与整理已计入本故事 | L / 14h | 保存真实问题记录和反对证据；S1–S2 合计目标 3–4 次；招募失败记录为依赖缺口，不宣称已验证 |

**Given / When / Then：**

- Given 候选引擎固定版本与可信策略，When 在 timebox 内重复执行最小 fixture，Then 记录规范化轨迹的一致性及能力缺口；完整 10 次回归留给 S3 正式适配器。
- Given 一项引擎不支持的能力，When 用户请求它，Then 返回能力错误，不能用默认模型静默替代。
- Given 干净 checkout，When 按文档运行开发入口，Then 无需作者机器上的隐式路径或私有数据即可验证。

**风险与退出：** 轨迹或许可问题使可行性未成立时，S2 不扩功能；先在本 Sprint 的剩余预算中缩减案例或更换适配目标，并修订 ADR。

**Given / When / Then：**

- Given `U` 跳过必要更新的订单簿片段，When 导入并请求连续回放，Then 该区间被拒绝或按显式策略隔离；重新同步不被记录为找回历史。

- Given 一个 ClaimRevision 引用冻结协议，When 修改费用或数据划分，Then 新建协议与 trial，旧运行仍可重现；仅命题变化才生成新的 ClaimRevision。
- Given 越界路径、symlink、过大输入或可执行序列化，When 进入 import，Then 在解析/发布前拒绝，目标目录外无副作用。

**风险与退出：** 无合法可发布真实样例时，使用可解释的合成 fixture；真实数据采集与再分发权限作为独立任务验证。

## Backlog 变更模板

每次改动记录：`故事 ID → 用户/技术证据 → 原验收 → 新验收 → 依赖与容量影响 → 被推迟范围 → 复核 Sprint`。保持故事 ID 稳定；拆分故事追加后缀，不复用已取消 ID。文档是初始计划的唯一来源，导入 GitHub issue 后用 issue 链接回填，避免两套互相矛盾的状态。
